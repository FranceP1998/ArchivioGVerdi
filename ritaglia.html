Ritaglia le parti

Pagina provvisoria e nascosta: da A4 mezzo vuoto ad A5, per tutti i file di un brano

Serve per le parti già divise in cui ogni file è un A4 con il contenuto in una sola metà. Scegli il brano, metti il riquadro A5 sulla metà piena (vale per tutti i file) e premi «Ritaglia»: ogni file viene sostituito con lo stesso nome e la metà vuota sparisce. Il Drive conserva comunque la versione precedente di ogni file («Gestisci versioni»).
